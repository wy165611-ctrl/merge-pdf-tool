# 本地 PDF 工具箱（macOS）

一个基于 SwiftUI、PDFKit 和 Vision 的本地 macOS PDF 工具。它从“PDF 合并”逐步扩展为页面级编辑、PDF 拆分和 PDF OCR 工具箱。PDF、图片和 OCR 任务优先在用户本机完成，不会主动上传文件。

## 当前功能

### PDF 合并

- 拖入多个 PDF、PNG、JPG/JPEG 等图片，或使用“添加文件”选择文件。
- 读取文件夹中的直接子文件，并跳过不支持的文件。
- 图片会作为单独页面加入，可与 PDF 混合排序后合并为一个 PDF。
- 支持手动拖拽排序、文件名自然排序、按截图文字排序和按自然语言关键词排序。
- 支持清晰化 PDF：轻度、标准、强化三档。清晰化适合扫描件，会将页面栅格化。
- 支持 PDF 压缩。清晰化开启时会先清晰化，再进行压缩。
- 合并时保留当前文件顺序和页面选择状态。

### 页面级预览与编辑

- 左侧显示已导入文件，中间显示当前文件的页面缩略图，右侧显示 PDFKit 大尺寸预览。
- 缩略图支持点击选择、多选、拖拽调整顺序、删除、左旋转、右旋转。
- 可以取消勾选页面，使其不参与最终合并；原始 PDF 文件不会被直接修改。
- 点击导出或合并时，应用根据当前页面顺序和旋转状态生成新的 PDF。

### PDF 拆分与页面提取

- 支持页码范围，例如 `1-3, 7, 10-15`，同时接受中英文逗号。
- 支持提取选中页面、删除指定页面后导出、每页单独导出和按固定页数分组拆分。
- 自动生成合理的输出文件名，并允许在保存面板中选择位置。
- 对空输入、非法格式、重复页码、越界页码、损坏 PDF、空 PDF 和加密 PDF 给出错误提示。

### PDF OCR

- 选择扫描版 PDF，逐页渲染为适合识别的图像。
- 优先使用 macOS Vision `VNRecognizeTextRequest`，支持简体中文和英文。
- Vision 不可用时，可回退到本机 Tesseract（需要自行安装语言数据）。
- OCR 在后台异步执行，显示“正在识别 X / Y 页”，支持取消。
- 可查看每页识别文本，并导出 TXT 文件。
- OCR 结果保留文本位置坐标，为后续 searchable PDF（可搜索 PDF）扩展预留数据结构；当前版本尚未生成透明文本层。

## 下载与安装

普通用户可以直接前往 [GitHub Releases](https://github.com/wy165611-ctrl/merge-pdf-tool/releases/latest) 下载最新的 macOS 压缩包。解压后将 `合并 PDF.app` 拖入“应用程序”文件夹即可使用；发布包与本地 `./build.sh` 生成的应用保持同一套源码和功能。

首次打开时，如果 macOS 因应用未经过 Apple 公证而拦截，请在 Finder 中右键应用选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。应用不需要联网才能执行 PDF 合并、页面编辑、拆分和 OCR。

## 构建与安装

需要 macOS 13 或更高版本、Swift 5+ 兼容的 `swiftc`，以及系统自带的 SwiftUI、AppKit、PDFKit、UniformTypeIdentifiers 和 Vision 框架。当前项目不依赖第三方 Swift Package，可在只有 Command Line Tools 的环境中构建：

```bash
./build.sh
```

应用产物位于 `build/合并 PDF.app`，可以双击打开，或运行：

```bash
open "build/合并 PDF.app"
```

截图 OCR 和 PDF OCR 的备用识别器需要 Tesseract 时，可以使用 Homebrew 安装：

```bash
brew install tesseract tesseract-lang
```

## 使用方法

1. 将 PDF 或 PNG、JPG/JPEG 等图片拖入窗口，或点击“添加文件”。需要批量读取时，点击“添加文件夹”。
2. 在左侧文件列表选择文件；中间页面列表会显示该文件的缩略图，右侧显示当前选中页的大图预览。
3. 使用页面列表的多选、拖拽、删除、旋转和勾选状态编辑最终页面集合。
4. 点击“合并为 PDF”导出当前文件和页面顺序。清晰化、压缩可按需开启。
5. 点击“拆分 PDF”选择源文件、拆分方式和页码范围，然后选择输出位置。
6. 点击“PDF OCR”选择扫描版 PDF，等待识别完成后查看文本或导出 TXT。
7. 使用“截图识别”或“粘贴顺序”时，应用会根据识别到的文件名或关键词调整当前文件列表；未匹配时不会删除原列表。

## 隐私说明

PDF、图片合并、页面编辑、拆分、清晰化、压缩和 OCR 均在本机处理。应用不会主动把 PDF、图片、页面图像或 OCR 文本上传到服务器。备用 Tesseract 也在本机运行。文件访问范围由用户在 macOS 文件选择器或拖放操作中授予。

## 技术架构

```text
Sources/
├── App/                 应用入口
├── Models/              输入文件和页面状态模型
├── Views/               SwiftUI 页面、拆分、OCR 和 PDFKit 预览视图
├── Stores/              合并、页面编辑、拆分和 OCR 状态管理
├── Services/            PDF 合并、拆分和 OCR 业务逻辑
└── Utilities/           应用通知等通用辅助代码
```

仓库中仍保留若干历史兼容的根目录 Swift 文件（例如截图 OCR、文件夹读取和 PDF 增强相关代码），它们被现有功能复用，后续可继续按风险拆分，不影响当前构建。

## 已知限制

- 当前不支持为加密 PDF 自动提供密码；加密 PDF 会被拒绝并提示用户。
- OCR 取消发生在页级任务边界，已经开始的当前页面识别完成后才会退出。
- 当前 PDF OCR 稳定输出为可查看、可复制的文本和 TXT；searchable PDF 透明文本层属于后续路线图。
- 清晰化会栅格化页面，可能影响原 PDF 的文字选择、链接、批注和表单交互。
- 超大 PDF 的 OCR 会限制单页渲染尺寸以控制内存；页面缩略图按需生成，不会一次性生成所有高清图像。

## Roadmap

- 生成保留原始扫描图像、带透明文本层的 searchable PDF。
- 进一步优化大 PDF 的缩略图缓存、后台生成和内存回收。
- 增加更多可自动化的 XCTest/CI 检查，并完善发布包、签名和应用截图。
